# ЕЩЁ ОДНО ВИДЕО — brainrot-одиссея

Сатирическая 2D action-adventure с видом сверху про ленту рекомендаций, ауру, «Могание» и бесконечное «ещё одно видео».
Написана на **Phaser 4.0.0** (Canvas/WebGL) + TypeScript. Вся графика рисуется процедурно (Canvas 2D), все звуки и музыка синтезируются через Web Audio API — внешних ресурсов, CDN и сетевых запросов нет.

## Запуск

Игра встроена в это Retool-приложение: откройте приложение (превью в редакторе или опубликованную версию) — игра запускается сразу во весь экран.
Если клавиши не реагируют — кликните по игре мышью (браузер отдаёт клавиатуру только активному фрейму). Звук включается после первого нажатия.

> Почему не `index.html` + `vendor/phaser.js` + `start.bat`: эта среда разработки — Vite-песочница Retool без доступа к файловой системе
> пакетов и без возможности положить в проект готовый файл библиотеки. Phaser подключён как npm-зависимость (`phaser@4.0.0`) и
> собирается вместе с приложением, поэтому для игры не нужны интернет, CDN или внешние сервисы. Код игры (папка `frontend/game/`)
> не зависит от React: React-обёртка `frontend/App.tsx` только создаёт `<div>` и вызывает `createGame(div)`.
> Чтобы перенести игру в автономный проект, достаточно любого бандлера (например, `npx vite`) с точкой входа, вызывающей `createGame(document.body)`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| SPACE | рывок (неуязвимость на время рывка, ломает стены с надписью «тонко») |
| E | Могание (дуэль ауры с персонажем рядом); без цели — аура-волна, тратит 20 ауры |
| F | говорить, читать, нажимать, подтверждать |
| Esc | пауза |
| 1–4, W/S + F | выбор ответа в диалоге |

## Сюжет и структура (8 глав)

1. **Фор-Ю** — улица-туториал: Скип (живая кнопка «Пропустить»), Повторяшка Гена, первая мог-дуэль, аура-волна, пазл «3 лайка», секретная комната.
2. **Академия ауры** — стражи «слишком сигма, чтобы разговаривать», двор с аура-ветром, магазин Стасяна, квест с вентилятором, секрет «постой 5 секунд», экзамен Декана.
3. **Секция комментариев** *(новая)* — хейтеры и турели, «закрепи 3 добрых комментария», Бабушка Капслок и челлендж на время, Король Ратио (**дуэль-комбо**), новая способность **«Ответ на хейт»** (аура-волна гасит снаряды), Петя-тролль с выбором ответа.
4. **NPC Live-арена** — шоу-«повторяшки», стримерша и подарки, Донатыч, модератор, поворот «ты в эфире с самого начала».
5. **Brainrot-полигон** — «правила дня», лава по расписанию, зеркальный двойник, Пельмень и Холодильник, предательство Скипа.
6. **Архив мемов 2007** *(новая)* — героя «шадоубанят» в архив забытых трендов: Медвед-олдфаг, дискеты и экспонаты, челлендж Танцующего Пикселя, Хомяк-архивариус (**дуэль «Невозмутимость»**: держи E и отпусти вовремя) и история происхождения Рекомендатора.
7. **Тёмная лента** *(новая)* — темнота, **стелс** от «Глаз Алгоритма» (конусы обзора, колонны-укрытия), бесконечный скролл-конвейер, Застрявший Олег, Надзиратель ленты и дуэль с **собственной версией героя из ленты**.
8. **Сервер Рекомендатора** — лазеры и босс из 4 фаз (кольца теперь используют комбо и невозмутимость), финал «ещё одно видео».

Финал: сцена дома, неожиданное возвращение кота из объявления первого уровня, экран статистики, «Новая игра».

## Сохранение

Прогресс сохраняется в `localStorage` на каждой контрольной точке (кольцевая лампа) и в начале уровня. «Продолжить» в меню
возвращает к последней точке. Если браузер запрещает `localStorage`, игра работает с сохранением в памяти до закрытия вкладки (об этом пишет сообщение у контрольной точки).
Победы над стражами/боссом-фазами фиксируются сразу, чтобы после смерти не перепроходить их.

## Где что менять

| Файл | Что внутри |
|---|---|
| `frontend/game/config.ts` | скорость, рывок, неуязвимость, здоровье, стоимость аура-волны, окна тайминга Могания, палитры уровней, музыка, фразы экрана смерти |
| `frontend/game/levels/level1..5.ts` | ASCII-карты уровней, NPC, диалоги, дуэли, скрипты событий |
| `frontend/game/levels/boss.ts` | фазы, атаки и реплики Рекомендатора |
| `frontend/game/ui/duel.ts` | механики Могания: `timing`, `rhythm`, `sequence`, `dodge`, `observe` |
| `frontend/game/scenes/world.ts` | легенда символов карт (`#` стена, `C` контрольная точка, `*` фрагмент, `%` тонкая стена, `~ ^` лава...) |
| `frontend/game/scenes/GameScene.ts` | игровой цикл и скриптовое API (`say`, `ask`, `duel`, `openGate`, `banner`...) и магазин |
| `frontend/game/art/*.ts` | процедурная графика персонажей и окружения |
| `frontend/game/audio.ts` | синтезатор звуков и музыки |

Пример новой дуэли в любом NPC уровня:

```ts
mog: async (g, npc) => {
  const win = await g.duel({ name: 'Новый босс', tex: 'guard1', kinds: ['dodge', 'observe'], hits: 3, speed: 1.2 })
  if (win) g.openGate('g1')
}
```

## Автотест

Откройте приложение с параметром `?selftest` в адресе — игра сама загрузит все 5 уровней, проверит достижимость
выхода/предметов/NPC, проведёт мог-дуэль, паузу, смерть и «Попробовать снова», финальную фазу босса и концовку,
а результаты выведет в консоль браузера с префиксом `[SELFTEST]`. Внимание: автотест перезаписывает сохранение.
